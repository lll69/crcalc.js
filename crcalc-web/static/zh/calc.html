CRCalc.js 高精度计算器

科学计算器 - 使用可滚动的高精度计算数学表达式，可精确到 1,000,000 位数字。

可以通过拖动、使用鼠标滚轮和方向键来滚动查看结果。

功能

  • 可滚动的高精度显示，支持显示 1,000,000 位及以上数字
  • 三角函数 (sin/cos/tan/sin⁻¹/cos⁻¹/tan⁻¹)
  • 双曲三角函数 (sinh/cosh/tanh/asinh/acosh/atanh)
  • 对数函数和指数函数
  • 支持阶乘计算，在 Chrome v100+ 上最高可计算 16,777,215!
  • 支持常数 e 和 π
  • 支持指数运算和平方根计算
  • 支持在弧度和角度模式之间切换
  • 支持复制结果和将结果保存到文件
  • 开源

注意

  • 某些函数（例如 x! 或 x^y）可能需要大量计算并且耗时很长。
  • Firefox 可能支持的可计算数字比 Chrome/Edge 少。
