CRCalc.js 高精度计算器

科学计算器 - 使用可滚动的高精度计算数学表达式，可精确到 1,000,000 位数字。

可以通过拖动、使用鼠标滚轮和方向键来滚动查看结果。

功能

  • 可滚动的高精度显示，支持显示 1,000,000 位及以上数字
  • 三角函数 (sin/cos/tan/sin⁻¹/cos⁻¹/tan⁻¹)
  • 双曲三角函数 (sinh/cosh/tanh/asinh/acosh/atanh)
  • 对数函数和指数函数
  • 支持阶乘计算，在 Chrome v100+ 上最高可计算 16,777,215!
  • 支持常数 e 和 π
  • 支持指数运算和平方根计算
  • 支持在弧度和角度模式之间切换
  • 支持复制结果和将结果保存到文件
  • 开源

注意

  • 某些函数（例如 x! 或 x^y）可能需要大量计算并且耗时很长。
  • Firefox 可能支持的可计算数字比 Chrome/Edge 少。

性能提示

  • 这个计算器使用 构造实数（Constructive Real）算术 来进行精确的任意精度计算。
  • 缓存常数（快速）：π 使用 Gauss-Legendre 算法进行二次收敛，并在不同精度请求之间缓存中间平方根结果。
  • 未缓存函数/常数（在极高精度下较慢）：^、e、exp、ln、sin、cos、tan、asin、acos、atan 及其双曲函数，每次请求更高精度时都会 从零开始 通过泰勒级数或牛顿迭代计算。滚动查看这些结果（上万位数字）会触发逐渐变慢的重新计算。

优化提示

  • π 和平方根高度优化 —— 可以随意滚动。
  • e、三角函数和对数值在超过 10,000 位时可能会变慢。
  • 对于小整数幂，使用乘法而不是 ^：x*x 比 x^2 快得多，x*x*x 比 x^3 快得多。幂运算符 ^ 即使在简单情况下也会退回到对数/指数计算（exp(y*ln(x))），这会涉及未缓存的泰勒级数求值。
  • 当可用时，使用 化简 按钮以获得化简表达式，而不是原始数字。

使用自定义变量和函数的说明

CRCalc.js 计算器支持定义变量 x、y、z 以及自定义函数 f、g。

1. 变量 x、y、z

  • 1. 定义变量

    1. 输入想保存的表达式，例如：3^6
    2. 点击 2ndF 进入第二功能模式。变量按钮会变成 →x / →y / →z 。
    3. 点击 →x / →y / →z 按钮。
    4. 成功定义后，该变量可以在后续表达式中使用。
    5. 再次点击 2ndF 退出第二功能模式。

    重新定义：重复上述步骤将覆盖旧定义。

  • 2. 使用变量

    • 点击 x / y / z 按钮输入对应变量，或用键盘输入变量名称。
    • 使用变量进行计算。例如：x+1
    • 按 = 或 Enter 键进行计算。
    • 如果变量尚未定义，计算将出现错误。

2. 函数f、g

  • 1. 定义函数

    1. 输入想保存的函数体，参数为 x。例如：x^2+1
    2. 点击 2ndF 进入第二功能模式。函数按钮将变成 →f(x) / →g(x) 。
    3. 点击 →f(x) / →g(x) 按钮。
    4. 成功定义后，将可以调用函数，格式如 f(2)、g(3) 等。
    5. 再次点击 2ndF 退出第二功能模式。

    重新定义：重复上述步骤将覆盖旧定义。

  • 2. 使用函数

    • 点击 f 或 g 按钮插入 f( 或 g(，或用键盘输入函数名。
    • 输入参数并填写右括号。例如：f(2)
    • 按 = 或 Enter 键进行计算。
    • 如果函数尚未定义，计算将出现错误。

3. 自定义变量和函数说明

  1. 定义时，所有变量和函数都是内联的
    在定义变量/函数时，定义中出现的其他变量/函数将使用定义中的值/表达式直接展开。 之后，更改被引用的变量/函数不会影响已经定义的变量/函数。

    示例1：

    1. 定义 x = 2。
    2. 定义 y = x + 1。
      此时，y 被内联化为 2 + 1，即 y = 3。
    3. 重新定义 x = 10。
      y 仍然是3，不会变成11。

    示例2：

    1. 定义 x = 3。
    2. 定义 f(x) = x^2 + 1。
      这里，x 是函数参数，不会被内嵌为 3。
    3. 定义 y = 5。
    4. 定义 g(x) = f(x) + y。
      此时，g 将当前 f 和 y 的定义嵌入，得到 g(x) = x^2 + 1 + 5。
    5. 修改 f 或 y 后，g 不会相应变化。
  2. 在函数定义中，x 是参数
    • 在定义函数时，函数体中的 x 被视为参数的占位符，而不是作为变量 x 内嵌。
    • 调用函数时，参数替换该 x。
    • 如果要在函数体中使用变量，请使用 y 或 z，而不是 x，否则它会被当作参数处理。
  3. 定义的顺序很重要
    • 先定义引用的变量/函数，然后再定义新的变量/函数。
    • 如果定义中引用了尚未定义的变量/函数，则会引发错误。
    • 由于定义是内联的，后续对基础变量/函数的更改不会自动更新已定义的上层变量/函数。
  4. 不支持递归
    在函数定义中引用自身不会按预期工作。
